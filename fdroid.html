MindTheClub without Google services

The same app, for phones with no Play Store and no Google services. Install it from our own repository and updates arrive like they do for any other app.

Install from Our F-Droid repository

Why our own repository and not the official F-Droid catalogue

The official F-Droid catalogue only lists apps whose every dependency is free software. MindTheClub uses Firebase Firestore, which is not, so it cannot be listed there. We would rather say that plainly than borrow the official badge and let you find out after you tap it.

So we run our own repository instead. It works the same way: you add it once to any F-Droid client, and from then on MindTheClub appears in your catalogue and updates like everything else. The repository is signed with our own key, and your client checks that signature at every update.

What we use of Google, and why

Notifications on this build do not go through Firebase. They use UnifiedPush, with the distributor you choose, so nothing Google is needed to wake the app.

What stays is Firestore, and the reason is interoperability. People using this build and people using the Play build are one single network: they find each other through one shared directory of identities. If this build had a directory of its own, the two halves could not talk to each other, and the point of MindTheClub would be lost.

That directory is storage and nothing else. It holds who you are and how to reach your phone. Messages, photos, files and calls never touch it: they travel straight from one phone to the other.

How to install

  1. Install an F-Droid client if you do not have one: F-Droid, Droid-ify or Neo Store.
  2. Tap the button above, or add this address by hand in your client: https://fdroid.mindtheclub.com/repo
  3. Install MindTheClub from the client.
  4. For notifications, install a UnifiedPush distributor such as ntfy, which is in the official F-Droid catalogue. Without one the app still works, but it only receives while it is open.

If you would rather not use F-Droid

Every release is also published as a signed APK on GitHub, with its SHA-256 next to it. Installed that way there are no automatic updates, so you have to come back and check now and then.

The source code of both builds is in the same repository, under GPLv3.

What it costs

The first 30 days are free, and the trial starts when you activate the app. After that the price is the same as on Google Play, billed every three months instead of monthly. You buy it on the web and activate it inside the app, which gives you a licence code that also travels inside your encrypted backup.
